# Archived verification runs

Verification runs older than the current `0.11.0` baseline, moved out of
`docs/verification.md`. See `archive/README.md` for the rules that apply here.

These rows record what was true when they were collected. Several exercise behaviour that
no longer exists — notably SSE-KMS/SSE-DSSE destination support (withdrawn in 0.11.0),
universal SHA-256 checksums, ACL reconciliation, and provider summary schemas v3/v4. Do
not cite them as evidence for current behaviour.

The current run log lives in `docs/verification.md`.
